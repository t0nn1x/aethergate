# Mobile export main-menu parallax missing (gray fallback only)

**Date:** 2026-02-11 23:27
**Files:** `src/Entities/Ui/GUI/MainScreen/background_controller.gd`
**Severity:** high

## Problem

Main menu background rendered on desktop, but disappeared on mobile/export builds. Users saw only the gray fallback behind the menu panel.

## Root Cause

Background discovery relied on `DirAccess` runtime directory/file enumeration under `res://`. In exported/mobile builds this can return empty/unavailable results even when resources are packaged and loadable, causing no parallax layers to be assigned.

## Solution

- Kept `DirAccess` path as primary for editor/desktop.
- Added export-safe fallback using deterministic probing with `ResourceLoader.exists()`:
  - Probe background folders (`Clouds 1..N`).
  - Probe sequential layer files (`1..N`) with common image extensions.
- Added explicit `[FIX][BackgroundController]` logs when fallback probing is used.

## Prevention

- Do not depend solely on `DirAccess` listing for runtime `res://` asset discovery in exported/mobile builds.
- Use predeclared manifests or `ResourceLoader.exists()` probing for packaged assets.
- Keep background loader logs for selected folder/layer and fallback mode to simplify device debugging.
