# iOS quit action UX fix (hide unsupported Quit button)

**Date:** 2026-02-12 01:20
**Files:** `src/Entities/Ui/GUI/MainScreen/main_screen.gd`
**Severity:** medium

## Problem

On iOS, tapping Quit produced repeated logs (`iOS runtime blocks programmatic app quit`) because iOS does not allow apps to quit themselves.

## Root Cause

Menu exposed a Quit action on a platform where programmatic quit is unsupported.

## Solution

- Added platform-specific UI rule in `MainScreen`:
  - Hide and disable Quit button on iOS.
  - Remove Quit from focus navigation chain automatically.
- Added guard in `_on_quit_pressed()` to ignore quit attempts on iOS.
- Kept deferred quit path for platforms where quit is supported.

## Prevention

- Do not surface lifecycle actions in UI when the current platform disallows them.
- Build focus chains from currently visible/enabled controls instead of fixed button assumptions.
