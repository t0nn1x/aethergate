# Invalid Camera2D API call in mouse world conversion path

**Date:** 2026-02-19 14:21
**Files:** `src/Gameplay/Player/Components/Input/player_input_component.gd`
**Severity:** high

## Problem

Runtime error on input handling:
`Invalid call. Nonexistent function 'get_screen_to_world' in base 'Camera2D'.`
This broke click-to-move flow at runtime.

## Root Cause

A non-existent Godot 4 API (`Camera2D.get_screen_to_world`) was introduced while trying to make screen-to-world conversion camera-aware.

## Solution

- Removed the invalid Camera2D call.
- Restored stable conversion through viewport canvas transform:
  `viewport.get_canvas_transform().affine_inverse() * screen_position`

## Prevention

- Verify Godot API names against 4.x docs before introducing new calls in core input paths.
- Prefer existing, previously working conversion primitives unless there is a confirmed engine API alternative.
- Smoke-test click/tap path immediately after changing input conversion methods.
