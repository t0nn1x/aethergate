# Windows launch opened windowed with bottom black bar (fullscreen mode mismatch)

**Date:** 2026-02-12 11:40
**Files:** `src/Core/platform_display_settings.gd`
**Severity:** medium

## Problem

On Windows, the game did not open in fullscreen and could show a black bar at the bottom instead of filling the display.

## Root Cause

`PlatformDisplaySettings` explicitly forced Windows to `Window.MODE_WINDOWED` at 1920x1080 and centered it using the monitor usable rect. This conflicted with the expected fullscreen startup behavior and could produce visible empty bars depending on monitor/taskbar/display scaling.

## Solution

- Replaced the Windows startup branch to apply fullscreen defaults (`Window.MODE_EXCLUSIVE_FULLSCREEN`).
- Matched window bounds to the target monitor before entering fullscreen.
- Added `[FIX][Display]` logs for desktop and Windows mode application to verify runtime behavior quickly.

## Prevention

- Keep platform display defaults aligned with intended UX (if startup should be fullscreen, do not force windowed mode in autoload overrides).
- Avoid using usable-rect centering logic for fullscreen startup paths.
- Keep startup display logs for platform/mode/screen resolution to simplify future regressions.
