# Splash screen logo disappeared after startup asset cleanup

**Date:** 2026-02-16 10:06
**Files:** `src/Entities/Ui/Splash/startup_splash_screen.tscn`, `src/Entities/Ui/Splash/startup_splash_screen.gd`
**Severity:** medium

## Problem

The custom startup splash no longer showed the branded logo. The splash scene still launched, but the logo texture was missing at runtime.

## Root Cause

`startup_splash_screen.tscn` referenced `res://Assets/studio_logo-transparent-bg.png`, but that asset was deleted in commit `695d2d08` and is no longer tracked. The scene kept a stale `ext_resource` path, so the splash loaded without the intended custom logo.

## Solution

- Updated splash scene texture reference to the existing asset: `res://Assets/studio_logo.png`.
- Added explicit startup/completion logs with prefix `[FIX][StartupSplash]` in `startup_splash_screen.gd`.
- Updated missing-texture warning to include `[FIX][StartupSplash]` for easier filtering.

## Prevention

- When removing or renaming assets, verify all `.tscn` `ext_resource path=...` references still resolve.
- Add a startup smoke check in CI/editor workflow that opens `run/main_scene` and reports unresolved resources.
- Keep splash-specific `[FIX]` logs to quickly distinguish missing-resource regressions from animation/timing issues.
