# Player silhouette covered only body layer instead of full assembled sprite

**Date:** 2026-02-23 16:44
**Files:** src/Entities/Player/player.tscn, src/Entities/Player/Components/Visual/player_visual_component.gd
**Severity:** medium

## Problem

Character silhouette/outline was visible for torso only, while legs and head had no silhouette.

## Root Cause

Silhouette implementation used a single silhouette sprite synced only with the body texture.
After switching to layered visuals (legs/body/head), silhouette sync logic was not updated to mirror all layers.

## Solution

- Replaced single silhouette sprite with layered silhouette sprites in `player.tscn`:
  - `SilhouetteLegs`
  - `SilhouetteBody`
  - `SilhouetteHead`
- Updated visual component sync logic to mirror texture/frame/flip/position for each corresponding part.
- Kept a legacy fallback path for older scenes that still use a single `Silhouette` node.

## Prevention

- Whenever visual representation is split into multiple sprite layers, duplicate supporting effects (silhouette/shadow/highlight) per layer.
- In code review, verify all sprite-sync helpers are updated after scene hierarchy changes.
- Add a regression smoke test: cycle cosmetics and verify silhouette covers legs/body/head at all animation frames.
