# Main menu background repeated as 4 tiled rows

**Date:** 2026-02-11 17:03
**Files:** src/Entities/Ui/GUI/MainScreen/background_controller.gd
**Severity:** medium

## Problem

Main menu background rendered as multiple repeated rows instead of a single composition layer.

## Root Cause

Background `TextureRect` nodes were set to `STRETCH_TILE` while the controller also expanded the draw rect. That caused the cloud texture to tile across the enlarged area. In addition, texture repeat was enabled in material setup.

## Solution

- Changed `stretch_mode` from `STRETCH_TILE` to `STRETCH_SCALE`.
- Disabled texture repeat (`TEXTURE_REPEAT_DISABLED`) for the layer.
- Kept horizontal shader scroll logic intact.

## Prevention

- Do not combine tiled stretch mode with composition-fit scaling unless explicit repetition is intended.
- Keep repeat flags disabled for single-composition backgrounds.
- Verify fit mode after changing composition zoom logic.
