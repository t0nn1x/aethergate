# Windows main-menu left-edge gap from parallax wrap seam

**Date:** 2026-02-16 10:18
**Files:** `src/Entities/Ui/GUI/MainScreen/background_controller.gd`
**Severity:** medium

## Problem

On Windows, the main menu could show a thin vertical gap/seam on the left edge of the screen. The issue was visible in the parallax cloud background while menu UI remained otherwise correct.

## Root Cause

Two rendering details combined:
1. Scroll shader wrapped UVs with `fract(...)` while layer texture repeat was disabled, which can expose a wrap seam on some platform sampling/compression paths.
2. Layer fit bounds were applied with unsnapped float offsets/sizes, so edge coverage could land on sub-pixel boundaries and reveal a tiny border.

## Solution

- Switched shader scroll from manual `fract` wrapping to continuous UV scroll (`uv.x += ...`) and enabled texture repeat on layer canvas items.
- Added pixel-snapped fit bounds with small configurable overscan (`layer_overscan_pixels`, default `2.0`) to guarantee full viewport coverage.
- Added startup `[FIX][BackgroundController]` logging for overscan/repeat settings.

## Prevention

- For scrolling backgrounds, keep UV repeat and sampling strategy aligned (do not disable repeat when shader depends on wrapped UV flow).
- Snap full-screen background rect bounds to integer pixels and keep slight overscan to avoid platform-specific edge artifacts.
- Include Windows render checks for 1px seams after any parallax/shader changes.
