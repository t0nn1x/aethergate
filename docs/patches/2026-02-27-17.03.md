# Main menu dimmer left-edge strip from non-zero overlay offsets

**Date:** 2026-02-27 17:03
**Files:** src/ui/Windows/Gui/MainScreen/main_screen.tscn, src/ui/MacOS/Gui/MainScreen/main_screen_macos.tscn, src/ui/Windows/Gui/MainScreen/main_screen.gd
**Severity:** medium

## Problem

Main menu tint/dimmer did not fully cover the left side of the screen. A visible vertical strip remained untinted on Windows, macOS, and mobile builds.

## Root Cause

`BackgroundDimmer` in both platform main-screen scenes had `offset_left = 18.0` with full-screen anchors, shifting the dimmer right and leaving an untinted left strip. Mobile also inherited the Windows main-screen scene via `UiManager`, so the same offset propagated there.

## Solution

- Set `BackgroundDimmer` horizontal offsets to full-screen coverage values:
  - `offset_left = 0.0`
  - `offset_right = 0.0`
- Added runtime fix logging in `MainScreen`:
  - cache `BackgroundDimmer` node by path
  - log dimmer rect + offsets with `[FIX][MainScreenDimmer]` on ready and viewport resize

## Prevention

- Avoid non-zero horizontal offsets on full-screen overlay/dimmer controls unless there is an explicit design reason.
- When reusing one UI scene across multiple platforms, validate overlay geometry in all profiles after scene tweaks.
- Keep targeted runtime logs for fullscreen overlays so seam regressions are visible immediately.
