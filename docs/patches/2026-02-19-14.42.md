# Restored creature click precision and moved desktop ground-pointer anchor to cursor nose

**Date:** 2026-02-19 14:42
**Files:** `src/Gameplay/Player/Input/player_mouse_input_adapter.gd`, `src/Gameplay/Player/Components/Input/player_move_pointer_component.gd`, `src/Gameplay/Player/Components/Input/player_input_component.gd`
**Severity:** medium

## Problem

After viewport-space mouse adjustments, creature click precision regressed and ground move pointer still felt visually below cursor nose.

## Root Cause

- Creature selection became less intuitive after switching desktop mouse capture away from the previous event-driven path that was already accurate for creature hit-tests.
- Ground move pointer visual anchor was centered on target world point, which made the marker appear below/right of the cursor nose on desktop.

## Solution

- Restored desktop mouse click/motion screen positions to `InputEventMouseButton.position` / `InputEventMouseMotion.position` in `PlayerMouseInputAdapter`.
- Kept debug logging for click conversion deltas.
- Added desktop-only visual anchor offset for move pointer marker:
  - `apply_desktop_click_anchor_offset`
  - `desktop_click_anchor_offset_world = Vector2(-3.0, -21.5)`
- Applied this offset when rendering pointer marker so ground click feedback appears at cursor nose instead of below it.

## Prevention

- Separate input-hit accuracy issues from visual-marker anchor issues; fix each in the correct layer.
- Keep pointer anchor offset configurable (exported) for fast per-project calibration without touching input math.
- Validate both creature selection and move marker placement together after cursor/camera changes.
